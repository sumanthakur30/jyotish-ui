# Sugam Jyotish UI

Angular 16 app — proxies `/api` → `jyotish-service` on `:8097`.

```powershell
cd D:\sugamFlow\sugamflow-astro\jyotish-ui
npm install
npm start
```

Open http://localhost:4600 — set tenant, manage birth profiles, click **Kundali** to generate D1 and open Overview / Planets / Houses.
